# Playground

A folder of small, self-contained prototypes. Each one is its own route, its own
folder, and its own problem. Nothing shared but the design tokens.

```bash
pnpm install
pnpm dev      # http://localhost:3000
```

## Add a prototype

```bash
mkdir prototypes/my-idea
```

```json
// prototypes/my-idea/meta.json
{
  "title": "My idea",
  "summary": "One sentence, under 140 characters.",
  "tags": ["misc"],
  "hue": 32,
  "date": "2026-11-20"
}
```

```tsx
// prototypes/my-idea/page.tsx
"use client";

export default function MyIdea() {
  return <div className="flex h-dvh flex-col pt-14">…</div>;
}
```

```bash
pnpm sync     # registers it on the index
```

Open `/p/my-idea`. That URL is permanent, so pick the slug for the idea.

## What lives where

| Path | What it does |
| --- | --- |
| `prototypes/<slug>/` | One prototype. Never imports from another prototype folder. |
| `lib/prototypes.generated.ts` | Generated by `pnpm sync`. Do not edit. |
| `app/p/[slug]/page.tsx` | Loads a prototype fullscreen, with the index escape hatch. |
| `app/globals.css` | The only place colour is defined. |
| `components/` | Shared UI, currently the card, the theme toggle, the provider. |
| `AGENTS.md` | Rules the coding agent follows. Change these, not the prototypes. |

## Deploy

```bash
pnpm deploy    # static export, then wrangler deploy
```

Live at **https://skufu-playground.zanemanilaph.workers.dev**.

The site is a static export served as Cloudflare Workers assets: no server runtime,
no API routes. `wrangler.jsonc` holds the worker name and the `out` directory, so
changing the name there changes the URL.
